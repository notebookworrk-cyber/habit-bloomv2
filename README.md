# HabitBloom v2

A premium habit tracking PWA with streaks, stats, and a cat companion.

## Tech Stack

- **Frontend:** Vanilla JS
- **Build:** Vite 5
- **Testing:** Vitest + Playwright
- **PWA:** Service worker + manifest

## Setup

```bash
npm install
npm run dev
```

## Features

- Habit tracking with streak counters
- Cat companion for motivation
- Statistics and progress visualization
- PWA installable for mobile/desktop
